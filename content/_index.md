# Welcome to Frostlabs

This is my personal space for a bit of everything: blog posts to act as brain dumps, project showcases, and homelab notes serving as a compendium of useful knowledge.

## How This Site is Built

This site is built using **Hugo**, a static site generator, and hosted on **Cloudflare Pages**. The source code is managed on **GitHub**, where Cloudflare automatically pulls, builds, and deploys any updates.
